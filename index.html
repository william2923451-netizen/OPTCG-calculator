航海王TCG 配DON!!計算器 v14 範例盤面

點角色改力量和能力，點領導者改手牌，HP 和 DON!! 在領導者兩側。紫色標籤是算出來的DON!!配法。

+N 我方：這回合最大壓力配法　對手：下回合最強配法

計算假設（看結果前請讀）
  • 【速攻】：角色登場的回合也可以攻擊（官方綜合規則 10-1-1-1）。在牌桌下方的速攻卡片設定雙方的速攻角色。
  • 解怪：只能攻擊橫置的角色。對手兩種應對都會算：讓角色死，或丟牌保它（只算全保或全不保）。推薦取對你比較差的那個結果。KO 時的效果、被擋時阻擋者會不會死，都沒有算。
  • DON!!：這回合貼出去或拿去下速攻的 DON!!，對手回合不能付反擊事件；需要留的時候結果區會提示。
  • 點領導者可設定領導者力量和手牌；HP、DON!! 在領導者兩側。
  • 反擊事件格式：費用C / +力量 / 張數 / 棄幾張手牌。「棄手牌的刀」要額外丟掉手牌，丟掉的牌也算進張數。
  • 卡片上「攻」= 會攻擊、「擋」= 阻擋者、「雙」= 雙重攻擊、劃紅線的「擋」= 不可被阻擋；虛線框 = 不攻擊。圖示灰色 = 沒有這個能力，點一下切換。
  • 攻擊一律打領導者，不算打角色、KO、效果、觸發（觸發可能直接翻盤）。
  • 假設防守方看得到你全部配法再決定怎麼擋（最保守）。實戰你可以攻擊之間再貼DON!!，所以先攻擊再決定DON!!通常比這裡算的更好。
  • 攻擊力 ≥ 防守力就命中；所以需要的反擊值 = 攻擊力 − 防守力 + 1000。
  • 阻擋者：每隻可擋一次任一可被阻擋的攻擊。你這回合有攻擊的角色會橫置，下回合不能阻擋。
  • 「受傷拿到的生命卡」選項把每張吃下的生命卡當成一張反擊加入手牌，對防守方偏樂觀。
  • 反擊事件可填多種，每種各自的張數、力量、費用；同一下攻擊可疊多張事件，總費用受防守方剩餘DON!!限制。事件的其他效果（KO、休息等）不計。
