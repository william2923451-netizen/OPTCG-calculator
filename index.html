航海王TCG 配DON!!計算器 v21 範例盤面

點角色改力量和能力，點領導者改手牌和牌組，HP 和 DON!! 在領導者兩側。橘色標籤是算出來的 DON!! 配法。

+N 我方：這回合最大壓力配法　對手：下回合最強配法

計算假設（看結果前請讀）
  • 【速攻】：角色登場的回合也可以攻擊（官方綜合規則 10-1-1-1）。在牌桌下方的速攻卡片設定雙方的速攻角色。
  • 速攻：v21 起不再手動設定，改從雙方牌組（環境牌組或匯入的清單）自動判斷。對手牌組裡的速攻會算進他下回合的最壞打法；你牌組裡的速攻只用在「斬殺機會」提示，不會假設你手上一定有。
  • 顯示模式：「簡單」只顯示局面判斷、速攻提示和四行結論；「詳細」顯示全部計算過程。
  • 速攻斬殺提示：拿牌組（環境牌組或匯入的清單）裡有【速攻】的角色逐張檢查。對手：單下這張就能打死你的列成威脅；你：這回合手上有這張就能斬殺的列成機會。速攻是從卡片文字判斷的，有條件才有速攻的卡也會被列入。
  • 我方環境牌組：只用在「對手視角」，代表對手知道你玩什麼牌組時，會估你最多有多少反擊、有哪些反擊事件。你實際手牌的計算不受影響。
  • 角色可以從環境牌組裡直接選，會帶入力量和關鍵字（阻擋者、雙重攻擊、不可被阻擋）；也可以照原本方式手動輸入。
  • 環境牌組：選對手的領導者，會帶入 optcg.one 比賽牌組統計出的共識牌組（2000／1000 反擊張數、反擊事件、速攻）。這是「大多數人怎麼組」，不是你對手實際的牌組。
  • 卡表來自 optcgapi.com（非官方資料站），在 GitHub 網路版才讀得到，Claude 預覽版會被擋。卡圖由資料站載入，版權屬於萬代。反擊事件、棄牌、速攻是從英文卡片文字判斷，有條件的效果可能判斷錯，請自己檢查。
  • 牌組匯入：卡片資料內建（optcg.one 目前環境比賽牌組用到的角色、反擊事件、領導者），不用連網；查不到的卡多半是沒有反擊的事件或舞台。太舊或太新的卡可能查不到。
  • 牌組匯入：對手擋法組合超過牌組裡的 2000／1000 反擊張數時，會標「牌組裡沒有這麼多」並視為擋不住。
  • 對手視角：對手看不到你的手牌和生命卡，所以把它們全部當未知，用跟「這回合」同一套算法算他的最大壓力配法，再拿你實際的手牌檢查擋不擋得住。
  • 解怪：只能攻擊橫置的角色。對手兩種應對都會算：讓角色死，或丟牌保它（只算全保或全不保）。推薦取對你比較差的那個結果。KO 時的效果、被擋時阻擋者會不會死，都沒有算。
  • DON!!：這回合貼出去或拿去下速攻的 DON!!，對手回合不能付反擊事件；需要留的時候結果區會提示。
  • 點領導者可設定領導者力量和手牌；HP、DON!! 在領導者兩側。
  • 反擊事件格式：費用C / +力量 / 張數 / 棄幾張手牌。「棄手牌的刀」要額外丟掉手牌，丟掉的牌也算進張數。
  • 卡片上「攻」= 會攻擊、「擋」= 阻擋者、「雙」= 雙重攻擊、劃紅線的「擋」= 不可被阻擋；虛線框 = 不攻擊。圖示灰色 = 沒有這個能力，點一下切換。
  • 卡片效果（v22）：認得環境牌組裡的部分戰鬥效果。防守加力（紅綠魯夫領導者每橫置 1 DON!! +2000、Kaido 領導者、白鬍子、琳琳、金獅子、Yamato 等）當成不佔手牌的反擊；只能對角色用、只加在領導者的條件都當成任何攻擊都能用。Enel 領導者算多 1 血。補血卡只在你下回合守不住時檢查，且假設你手上有那張卡、條件成立。Captain John 鎖定、Shanks 登場橫置、Cabaji／Koby 對手回合加力也有算。其他效果沒算。
  • 觸發補血（v24）：只有「生命 0 時補 1 血」這種觸發會被算（目前環境只有 OP06-115）。用牌組裡的張數÷牌組張數估「最後一張生命是它」的機率；HP 設定裡最後一張生命已知時不算。翻到後重算一次：補 1 血、丟 1 張手牌、那張觸發不進手牌。黃色角色的【觸發】登場效果大多寫【自己的回合】，在對手回合翻到不會補血，所以不算。其他觸發（KO、橫置、登場阻擋者）沒有算。
  • 我方「已橫置」（v24）：代表這回合已經攻擊過，不再參與這回合攻擊，對手回合也不能阻擋。用來在解怪後調整剩下的攻擊。
  • 阻擋者會死（v25）：你的攻擊力 ≥ 對手阻擋者力量時，阻擋者被 KO。對手會先用擋了不會死、或下回合本來就不攻擊的阻擋者。只有「不擋就守不住」時才當成他一定會擋，下回合少那隻攻擊者；否則照他不擋（對你最不利）算，另外列出擋了的結果。解怪比較裡的各種打法沒有算阻擋者死亡。
  • 我方角色左上的「橫」：設成已橫置（攻擊或解怪用過了），不會再攻擊，下回合也不能阻擋。打完一部分後把用過的角色按「橫」、把被解掉的對手角色移除，就能重算剩下怎麼打。
  • 【DON!!×1】（v27）：紅綠魯夫領導者效果要領導者身上有 DON!!。你方照這回合配法有沒有貼到領導者判斷；對手方在對手領導者面板設定（預設有）。
  • 少見卡（v26）：選環境牌組時，不到 4 成牌組有放的反擊事件、速攻、補血卡會列出來並附比例，預設不算；在領導者面板按「算進去」才會加入計算。
  • 攻擊一律打領導者，不算打角色、KO、效果、觸發（觸發可能直接翻盤）。
  • 假設防守方看得到你全部配法再決定怎麼擋（最保守）。實戰你可以攻擊之間再貼DON!!，所以先攻擊再決定DON!!通常比這裡算的更好。
  • 攻擊力 ≥ 防守力就命中；所以需要的反擊值 = 攻擊力 − 防守力 + 1000。
  • 阻擋者：每隻可擋一次任一可被阻擋的攻擊。你這回合有攻擊的角色會橫置，下回合不能阻擋。
  • 「受傷拿到的生命卡」選項把每張吃下的生命卡當成一張反擊加入手牌，對防守方偏樂觀。
  • 反擊事件可填多種，每種各自的張數、力量、費用；同一下攻擊可疊多張事件，總費用受防守方剩餘DON!!限制。事件的其他效果（KO、休息等）不計。
